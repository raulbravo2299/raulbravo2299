
# Korean Lotto Number Generator

## Overview

A simple web application to generate Korean lottery numbers.

## Project Outline

### Style and Design

*   **Layout:** Centered content with a clean and simple interface.
*   **Colors:** A modern color palette.
*   **Typography:** Clear and readable fonts.
*   **Iconography:** Use of a lottery ball icon.
*   **Animation:** Subtle animations on button press and number generation.

### Features

*   Generate 6 unique random numbers between 1 and 45.
*   Display the generated numbers in a visually appealing way.
*   A button to trigger the number generation.

## Current Plan

1.  **HTML:** Structure the page with a title, a button, and a container for the numbers.
2.  **CSS:** Style the elements for a modern and clean look.
3.  **JavaScript:** Implement the lottery number generation logic.
